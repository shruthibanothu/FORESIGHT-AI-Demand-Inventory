# FORESIGHT – AI-Powered Demand & Inventory Intelligence

An AI-powered platform for demand forecasting and inventory intelligence.

## 🚀 Live Demo

[Click here to open FORESIGHT Live App](https://foresight-ai-demand-inventory-omhe.onrender.com/)

## 📂 Project Files

- `app.py` – Streamlit application
- `foresight_output.csv` – Forecast and inventory intelligence results
- `requirements.txt` – Python dependencies

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Streamlit

## 🎯 Features

- SKU-level demand forecasting
- Inventory risk detection
- Stockout prediction
- Reorder recommendations
- Interactive dashboard
